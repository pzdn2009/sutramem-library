# SutraMem Library

善念 App 的公开内容仓库。标准佛经不在这里重复维护，由 App 通过 Deerpark 搜索和下载。

本仓库只维护以下四类内容：

| 板块 | 入口 | 用途 |
| --- | --- | --- |
| 咒语 | `catalog.json`、`books/` | Deerpark 不一定收录或不便编辑的咒语、分会结构及发音修正 |
| 仪轨 | `catalog.json`、`books/` | 烟供、供灯、上香等实践内容 |
| 音视频 | `media/catalog.json` | 可播放、下载或跳转的音频及视频资源 |
| 法讯 | `events.json` | 寺院、活动时间、地点、报名链接与来源 |

## 内容边界

- 标准经文正文以 Deerpark 为来源，不上传到本仓库。
- 咒语可以人工整理，因为不同版本的分段、字形与读音可能不同。
- 仪轨必须注明来源、适用范围及必要的安全提醒。
- 音视频和法讯必须保留原始来源链接，不在仓库内复制无授权媒体。
- App 中的个人进度、记忆要点和个人发音修正只保存在用户本地。

## 咒语编辑

每部咒语使用稳定 ID，例如 `mantra.shurangama.zh-hant`。正文可以按会或段拆成多个 UTF-8 文本文件，并在 `catalog.json` 中使用 `kind: "mantra"` 登记。

特殊读音直接附在对应文字后：

```text
地{dì}藏{zàng}
重{chóng}
```

普通经文只需要标注需要纠正的字；像楞严咒这类需要完整注音的内容，可以逐字标注。其余文字继续使用系统普通话发音。修改正文或拼音后必须提高版本并重新计算 SHA-256。

文本来源与许可见 [SOURCES.md](SOURCES.md)，媒体来源见 [media/SOURCES.md](media/SOURCES.md)。
